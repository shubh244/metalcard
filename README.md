# CardForge

Premium credit card offer website for India — compare fees, rewards, lounges and estimated annual value.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — metal hero landing
- `/cards` — catalog + filters
- `/cards/[slug]` — card detail
- `/compare` — side-by-side
- `/quiz` — find my card
- `/calculator` — reward value
- `/banks/[bank]` — bank landing
